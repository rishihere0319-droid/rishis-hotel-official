🍽️ Rishi Online Food Ordering Website
Rishi Online Food Ordering is a responsive web-based food ordering application built using HTML, CSS, and JavaScript.
It allows users to register, login, browse food items, add items to cart, and complete orders with different payment options.

🚀 Features
🔐 User Registration & Login System
🔎 Search Food Items
🛒 Add to Cart Functionality
💰 Automatic Total Price Calculation
💳 Multiple Payment Options (UPI, Card, Cash on Delivery)
✅ Order Confirmation with Cart Reset
📱 Responsive Design (Mobile Friendly)
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Font Awesome (for icons)
📂 Project Structure
index.html – Contains complete HTML, CSS, and JavaScript code
Food Images – JPEG/JPG image files used in the menu
▶️ How to Run the Project
Download or clone the repository.
Make sure all image files are in the same folder as index.html.
Open index.html in any web browser.
Register or login to start ordering food.
🎯 Project Purpose
This project is created for learning and practicing:

Frontend web development
DOM manipulation
Basic e-commerce logic
Responsive UI design
